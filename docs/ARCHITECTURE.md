# Architecture

Gold research is separated from virtual execution:

1. **Provider layer** retrieves public data with fixed GET endpoints, explicit timestamps, private validated-response caching, a host allowlist, bounded attempts, bounded reads and strict validation. The local CSV is an explicit alternative, never an instrument substitution.
2. **Technical and research layer** normalizes closed bars, computes statistics and folds, then writes snapshot.json. Continuous UTC buckets discard incomplete resampling buckets. Market sessions are indicative windows using IANA timezones and explicit NY date overrides, with no exchange holiday automation.
3. **Host workflow** uses snapshot.json and workflow.json. Initial role packets exclude prior work. The next rounds record actual opposing reviews, independent criticism, optional targeted evidence, explicit revisions and a final view. Sources have stable content-derived IDs. The lead serializes writes. Workflow integrity hashes detect accidental snapshot edits; they are not an adversarial signature.
4. **Virtual simulator** queues an entry hypothesis separately. Sizing proposes virtual ounces. A dedicated risk function independently checks a fingerprint of the plan, fill inputs and state. The broker calls that gate itself in a SQLite write transaction. Account state and event history commit atomically. A director or submitted agent cannot authorize execution or override a veto. The research report never trades.
5. **Historical replay** uses the same execution kernel, warmup only from earlier bars, and expanding train windows with disjoint forward tests. Three preregistered breakout lookbacks are selected by expectancy penalized for small samples and drawdown; the fixed 20 default is disclosed if there is no support. Folds reset virtual cash and positions. Cash and all-virtual spot buy-and-hold are benchmarks. No best-fold selection.

## Timing and fill assumptions

Candle timestamps designate completed UTC bars. Signal uses only observed closes, and entry uses the first contiguous later candle's opening reference after its OHLC is available, never the signal's closing price. The theoretical next open and previous close share a time boundary; their prices need not match. This models zero added decision latency at the boundary, not an executable intrabar observation. A missed first candle cancels the entry. Paper state advances on closed bars observed by the engine. An ambiguous stop and target is resolved stop-first. A gap beyond the stop uses the adverse observed open; a favorable gap gets no improvement. Non-contiguous holding bars emit data-gap records and use only the next observed bar. Price basis is mid/indicative; half spread, slippage per side and proportional commissions are modeled, not measured. Drawdown uses marked closes, omitting unobservable intrabar paths. Quote engines are not tested for market microstructure, spread widening, financing or partial fills.

Monte Carlo uses contiguous trade-P&L blocks and a deterministic random seed. The bootstrap confidence interval is conditional on sparse modeled out-of-sample trades. No macro history enters the replay because the imported public series may be revised or lack reliable publication timestamps. Daily correlation uses matched date observations and is descriptive. Simulations cannot establish a real-world trading edge.

The CSV adapter's `synthetic` flag is propagated to the report. An offline demonstration never submits mock discussions as real. Agent workflow tests use explicit synthetic responses only. Without fresh spot data, or with only synthetic observations, the report's conclusion is insufficient evidence regardless of any submitted view.
