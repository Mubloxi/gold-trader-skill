# Data contracts and access

Data-source and platform documentation consulted 25 November 2026. These links describe access, not a guarantee that an account has the right entitlements or that a particular server is reachable. The code is MIT; market observations and articles retain their own terms. No third-party market data is bundled. Do not republish raw licensed feeds or use them to train models; confirm the terms for each provider and series before automated use, caching, display or distribution.

| Coverage | Adapter and provenance | Timing, access and limits |
| --- | --- | --- |
| XAU/USD spot | [Twelve Data instrument](https://twelvedata.com/symbols/commodity/xau-usd), [API](https://twelvedata.com/docs), [terms](https://twelvedata.com/terms); alternatively a local OHLC export with explicit metadata | Optional API key in Authorization header; inspect your plan for commodity and intraday entitlement and credits. Bar open timestamps converted to UTC close timestamps. No real-time guarantee. Use a lawful export or a synthetic fixture without an account. |
| Nominal/real Treasury yields | [US Treasury XML](https://home.treasury.gov/treasury-daily-interest-rate-xml-feed) fallback; [DGS10](https://fred.stlouisfed.org/series/DGS10), [DFII10](https://fred.stlouisfed.org/series/DFII10) | Daily observations on business days, not tick quotes. Percent, not basis points. |
| Broad USD, Fed policy | [DTWEXBGS](https://fred.stlouisfed.org/series/DTWEXBGS), [DFEDTARU](https://fred.stlouisfed.org/series/DFEDTARU), [Fed monetary RSS](https://www.federalreserve.gov/feeds/feeds.htm), [meeting calendar](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) | Latest vintage through keyless chart CSV export; Fed headlines via RSS, announcement schedule via timestamped source input. Trade-weighted broad USD is not ICE DXY. |
| CPI, PPI, payrolls | [BLS calendar](https://www.bls.gov/schedule/news_release/), [BLS public API](https://www.bls.gov/developers/api_signature_v2.htm), [FRED CPI](https://fred.stlouisfed.org/series/CPIAUCSL), [PPI](https://fred.stlouisfed.org/series/PPIACO), [payrolls](https://fred.stlouisfed.org/series/PAYEMS) | Use the BLS published ICS for dated releases and FRED chart CSV for observations. PPIACO is all commodities; it is not final-demand PPI. Add specifically labeled final-demand releases as separate evidence. |
| PCE, GDP | [BEA release schedule](https://www.bea.gov/news/schedule), [FRED PCEPI](https://fred.stlouisfed.org/series/PCEPI), [GDPC1](https://fred.stlouisfed.org/series/GDPC1) | Monthly and quarterly, respectively; revisions and publication dates matter. Latest-vintage values cannot be joined into point-in-time simulations. Add scheduled and/or released BEA numbers with source and publication time as verified evidence. |
| FRED usage | [FRED API docs](https://fred.stlouisfed.org/docs/api/fred/overview.html), [data attribution](https://fredhelp.stlouisfed.org/fred/about/about-fred/can-i-use-fred-data-elsewhere/), [terms](https://fred.stlouisfed.org/legal/) | Uses public chart CSV downloads, not a credentialed API. Use is optional. No promise of redistribution rights, stale/fresh labels are age heuristics, and the data may be revised. |
| COMEX, DXY and CFTC | [CME Gold](https://www.cmegroup.com/markets/metals/precious/gold-futures.contractSpecs.html), [ICE DXY](https://www.ice.com/market-data/indices/fx-indices/nyse-us-dollar-index), [CFTC disaggregated futures only](https://publicreporting.cftc.gov/Commitments-of-Traders/Disaggregated-Futures-Only/72hh-3qpy) | CFTC keyless filtered JSON for COMEX contract code 088691, reports dated for the position observation and generally published later; no inferred release timestamp. For futures quotes, import the exact contract month and timestamp as separate evidence. No synthetic basis series or substituted DXY. |
| Central banks, ETFs and PMI | [WGC central bank gold reserves](https://www.gold.org/goldhub/data/gold-reserves-by-country), [WGC ETF flows](https://www.gold.org/goldhub/data/gold-etfs-holdings-and-flows), [S&P Global PMI calendar](https://www.spglobal.com/marketintelligence/en/mi/products/pmi.html) | Capture published values and units via the timestamped evidence schema. Fund holdings, flows and central bank reserve changes are different series. Report release lags and any login, data license or coverage restrictions. |
| Geopolitics, breaking headlines, liquidity | Fed monetary RSS and verified source notes; prefer official releases and independently confirm consequential reports | News headlines are leads; use title and publisher URL deduplication. The desk has no universal wire service. No centralized spot gold volume; bid/ask depth or venue volumes require separately labeled evidence. |

When forming a thesis: compare dollar, nominal and real yield changes alongside price structure, note timing mismatches, and flag macro evidence that contradicts technical evidence. A price/yield association is descriptive and may change or reverse. Do not infer market intent from delayed COT or infer that spot, CFDs, futures and ETFs share execution prices, spreads or hours.

A source failure never creates a substitute price. Twelve Data can fall back to an explicit schema-checked local spot CSV; Treasury yields can fall back from FRED to Treasury. Cache only validated responses, preserve retrieval time and report access failures. Cache is private, local and removable. Provider egress is restricted to a fixed HTTPS host allowlist; no redirects and no key in URL. Shared or repeated invocations should not run multiple network fetches in parallel against the same cache.
